# TRMNL Dash

See your token and API usage across popular AI coding agents on your [TRMNL](https://trmnl.com/) device.

## Supported agents

- Claude Code
- OpenAI Codex
- Google Antigravity
- More to come

## Web dashboard

A simple web dashboard (React + Vite) lets you customize what's shown on your TRMNL and manage your agent connections and authentication.
